# Angular Dex

A lightweight Pokédex built to learn and practice modern Angular and Tailwind CSS.

## Technologies
- <b>Frontend:</b> Angular, Tailwind CSS
- <b>Third Party API:</b> <a href="https://pokeapi.co/" target="_blank">PokéAPI v2</a>

## Features
- Search Pokémon by name
- View sprite, type(s), and Pokémon description
- Save Pokémon to favorites
